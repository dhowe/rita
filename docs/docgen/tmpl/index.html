RiTa† is an open-source library for writing in computational environments. It provides functions for simple language processing and generation tasks without the overhead or complexity of a full NLP stack. Designed to be small and easy to use, it runs in the browser, p5.js, Processing, Node and Android.

Features include text generation, inflection, conjugation, stemming and tokenization, and analysis of English features such as part-of-speech, phonemes, syllables and stresses. RiTa's customizable lexicon can be searched via partial matches on combinations of any of those features, and a letter-to-sound engine allows analysis of words not in the lexicon. It also includes a powerful context-free-grammar-based scripting language designed for writers (RiScript).

RiTa Version 4

Unbounded N-grams

A complete rewrite of the Markov generator, efficiently employing unbounded (infinite) N-grams.

RiScript built in

Integration of the RiScript scripting language, designed for writers.

Letter-to-sound

Feature analysis of arbitrary words, with or without a lexicon.

Smart lexicon search

Match words by part-of-speech, syllable count, stress and rhyme patterns.

Heuristic transforms

Inflection, conjugation, stemming, tokenization, and more.

Powerful generation

Rich options via context-free grammars and Markov chains.

Important changes

  • Nearly all features are now static functions on the RiTa object, so there is only one object to import: RiTa.phones(), RiTa.tokenize(), RiTa.conjugate(), and so on.
  • RiMarkov and RiGrammar are now accessed via RiTa.markov() and RiTa.grammar(), and are significantly improved. Grammars are still JSON-compatible but can now include all the features of RiScript, and use the choice primitive via square brackets — e.g. [ unicorn | wizard | elf ] — rather than parentheses.
  • RiScript is a scripting language designed specifically for writers, enabling easy integration of static text with algorithmic elements (choices, sequences, transforms, gates, etc). It can be run via RiTa.evaluate() or included in any RiTa grammar. Details here.

Archives of versions 1.x, 2.x and 3.x are available.

What it does

Generation

Text generation via Markov chains and context-free grammars, with built-in support for RiScript.

Lexicon search

Match part-of-speech, syllable and letter count, stress, soundex and rhyme (regex) patterns.

Word tools

Modules for tokenization, inflection, stemming, verb conjugation and concordance/KWIC models.

Unknown words

A customizable lexicon with a letter-to-sound algorithm for analysis of words it doesn't contain.

Taggers

Granular features including phonemes, stress, part-of-speech and syllables.

Runs anywhere

Node or the browser, with or without p5.js and Processing. Also Android.
